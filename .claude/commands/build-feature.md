When asked to build a feature:
1. Read CLAUDE.md and relevant docs/* files.
2. Inspect existing code before proposing changes.
3. Produce a concise plan with:
   - Scope
   - Files to change
   - Risks
   - Tests
4. Wait for confirmation only if the request is ambiguous or destructive.
5. Implement in small steps.
6. Run lint/tests for affected areas.
7. Summarize changed files and any remaining gaps.
