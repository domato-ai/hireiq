# Product Spec

## Product
HireIQ — a hiring decision workspace for SMBs, agencies, and recruiters.

## Primary job to be done
Help users shortlist strong candidates faster, with defensible reasoning.

## Core workflow
1. Create workspace
2. Add role / job description
3. Upload resumes or connect OneDrive
4. Parse + structure candidates
5. Retrieve best-fit candidates
6. Apply weighted scoring rubric
7. Review shortlist and evidence
8. Generate interview packs / notes

## Non-goals for V1
- ATS replacement
- Full HRIS
- Outbound sourcing
- Automatic rejection emails
- Multi-tenant enterprise hierarchy beyond basic org/workspace

## V1 screens
- Login / signup
- Workspace list
- Role detail page
- Upload panel
- Candidate list + filters
- Candidate compare drawer
- Candidate detail panel
- Billing / plan page
- Settings / integrations

## Success metrics
- Time to first shortlist
- Resumes processed per role
- Shortlist acceptance rate
- Paid conversion from free tier
- Weekly active hiring workspaces
