# UI Direction

## Core mood
Editorial × operations console × due diligence workspace.

## Do
- Create a bold first-use screen
- Use strong typography with character
- Use asymmetry intentionally
- Prioritize compare-and-decide workflows
- Make scoring feel auditable
- Create visual anchors for strengths, risks, and missing evidence

## Don't
- No chat-first homepage
- No giant empty dashboard cards
- No "magic AI" marketing copy
- No purple gradient SaaS visuals
- No generic component-library look

## Signature elements
- Fixed evidence rail on candidate detail
- Layered shortlist table with sticky columns
- Weighted score bar with visible factor breakdown
- Comparison mode with side-by-side strengths / gaps
- Confidence tags: strong evidence / weak evidence / not found

## Motion
- Restrained, sharp, deliberate
- Use motion for transitions of evidence and ranking changes
- No playful loader nonsense on core professional screens

## Visual direction
- Editorial and operational, not futuristic
- Dramatic typography with restraint
- Structured surfaces and evidence rails
- Compact but readable tables
- Meaningful contrast
- Premium feeling without luxury cliches

## Key layout: Role workspace
- Left = upload/status/context
- Center = ranked candidate table
- Right = evidence / compare / risks

The page should communicate seriousness, speed, and defensibility.
